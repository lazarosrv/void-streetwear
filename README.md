# VOID — Streetwear

Projeto de uma loja virtual demonstrativa de roupas e acessórios streetwear, desenvolvido para praticar e demonstrar habilidades em desenvolvimento web.

## Demonstração

Acesse o site: https://glowing-chimera-5a3853.netlify.app

## Funcionalidades

* Catálogo de produtos com imagens e preços.
* Filtros por categoria.
* Carrinho de compras interativo.
* Adição, remoção e alteração da quantidade de produtos.
* Cálculo de subtotais e valor total.
* Salvamento do carrinho com LocalStorage.
* Preparação de pedidos para envio pelo WhatsApp.
* Layout adaptável para diferentes telas.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Netlify

## Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo `index.html` no navegador.
3. Teste os produtos, os filtros e o carrinho.

## Objetivo

Praticar desenvolvimento front-end, manipulação do DOM, funções, arrays, objetos, eventos e publicação de sites.

## Estado do projeto

Projeto demonstrativo em desenvolvimento. Não possui integração com processamento de pagamentos nem sistema de gestão de pedidos.
